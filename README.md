# Health Check (React)

Enter height, weight, waist and optional blood sugar and blood pressure readings.
The app compares each value with standard reference ranges and shows a report with recommendations.

## Setup

1. Install Node.js 18 or newer.
2. Run `npm install`.
3. Run `npm run dev` and open the URL shown in the terminal.
4. Run `npm run build` to create a production build in `dist/`.

This app gives general screening information only. It is not a medical diagnosis.
